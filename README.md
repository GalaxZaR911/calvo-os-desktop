## Acerca de CaLvo.OS

Distribucion GNU/Linux minimalista basada en Debian 13 Trixie, desarrollada como proyecto academico de Sistemas Operativos.

## Caracteristicas

- Gestor de ventanas i3.
- Polybar y LightDM.
- Terminal Xterm.
- Firefox ESR incluido.
- Fondo de pantalla personalizado.
- Identidad visual propia.
- Modo Live.
