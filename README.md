## CaLvo.OS V2.2 — Version principal

- Debian 13 Trixie AMD64.
- Gestor de ventanas i3 sobre X11.
- Modo Live e instalador grafico Calamares.
- Tematica personalizada Dark Gold.
- Logotipo Golden Calvo.
- Terminal personalizada y CalvoFetch.
- Polybar y Rofi.
- Firefox ESR y Thunar.
- Gestion de red y sonido.
- ISO inferior a 1 GB.

| Super + D | Menu de aplicaciones |
| Super + E | Explorador de archivos |
| Super + B | Navegador |
| Super + P | Menu de energia |
| Super + Shift + Q | Cerrar ventana |
