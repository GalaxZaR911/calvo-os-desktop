# Versiones de CaLvo.OS

Cada versión refleja una etapa diferente del proyecto.

| Versión | Lo que aportó | Para qué probarla | Estado |
|---|---|---|---|
| V0.1 Genesis | Primera Live ISO de consola | Aprender arranque y comandos Linux | Histórica |
| V0.2 First Desktop Alpha | Primer escritorio i3/X11 | Comparar la primera interfaz | Histórica |
| V2.1 Dark Gold Lite | Identidad Dark Gold y optimización a 830,47 MB | Probar el escritorio Live publicado | Publicada, sin instalador |
| V2.2 WM i3/X11 | Calamares integrado y enfoque WM | Verificar instalación BIOS | ISO compilada, pruebas pendientes |
| V2.2 WM Sway/Wayland | Segunda variante WM sobre Wayland | Verificar instalación UEFI | ISO compilada, pruebas pendientes |
| Futura edición DE | Entorno de escritorio completo | Proyecto posterior a WM | Planeada |
